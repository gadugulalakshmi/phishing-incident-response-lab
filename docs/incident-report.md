# Security Incident Report

## 1. Incident Overview

- Incident Name: Phishing Attack Leading to Account Compromise
- Organization: Acme Corp (Simulated)
- Affected Account: alice
- Severity: High (Initial Assessment)
- Incident Type: Phishing / Credential Compromise
- Status: Simulated Investigation Completed

## 2. Executive Summary

A simulated phishing incident was investigated in which an employee
clicked a suspicious link and submitted account credentials. Shortly
afterward, successful authentication activity was observed from an
unusual source IP address.

The available sample logs indicate potential account compromise.
Further validation would be required in a real environment.

## 3. Evidence Reviewed

- Sample authentication logs
- Phishing link interaction event
- Credential submission event
- Successful and failed login events
- Indicators of Compromise document
- Incident timeline

## 4. Key Findings

- The user interacted with phishing content.
- Credentials may have been exposed.
- Authentication occurred from an unusual source IP.
- A successful login followed the suspicious activity.
- The sequence of events is consistent with possible account compromise.

## 5. Recommended Response

- Restrict the affected account.
- Revoke active sessions and authentication tokens.
- Reset credentials and verify MFA.
- Investigate account activity for unauthorized changes.
- Block confirmed malicious indicators.
- Preserve relevant logs and evidence.
- Monitor for additional suspicious activity.

## 6. Recovery and Prevention

- Restore account access only after security checks.
- Continue enhanced authentication monitoring.
- Improve phishing awareness training.
- Review email security and authentication controls.
- Update the incident response playbook.

## 7. Lessons Learned

The simulated incident demonstrates the importance of correlating
phishing events with authentication logs. Timely detection, effective
containment, evidence preservation, and documented response
procedures can reduce the impact of account compromise.

## 8. Project Limitations

This is a simulated training lab using sample data. The IP address,
events, and investigation findings have not been independently
validated against a real production environment.

## 9. Conclusion

The exercise demonstrates a structured approach to investigating a
suspected phishing-related account compromise and documenting
response recommendations.
