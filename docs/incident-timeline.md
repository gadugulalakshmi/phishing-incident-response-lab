# Incident Timeline

## Incident
Phishing Attack Leading to Account Compromise

| Time | Event | Analysis |
|---|---|---|
| 10:00:12 | Successful login from normal IP | Normal user activity |
| 10:05:31 | Phishing link clicked | User interacted with phishing content |
| 10:07:45 | Credentials submitted | Credentials may have been exposed |
| 10:12:03 | Successful login from unknown IP | Suspicious authentication activity |
| 10:13:17 | Failed login from same IP | Possible unauthorized access attempt |
| 10:14:02 | Successful login from same suspicious IP | Strong indicator of possible account compromise |

## Timeline Assessment

The incident began when the user interacted with a phishing link and
submitted credentials. Shortly afterward, authentication activity
from an unusual source IP was observed.

The successful login from the suspicious source following credential
submission is consistent with a potential account compromise.

## Incident Status

Potential account compromise confirmed for investigation and
containment.
